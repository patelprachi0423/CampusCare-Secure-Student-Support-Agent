# Attendance Policy
Students should attend scheduled classes regularly. Contact the academic office if an absence needs to be documented. Check the institution's official rules for minimum attendance requirements.

# Fee Payment
Students can review their fee status through the authorized student portal. If a payment is missing, keep the transaction reference and contact the accounts office. Never share passwords, OTPs, or banking credentials.

# Scholarship Applications
Scholarship eligibility and deadlines vary by scheme. Read the official scholarship notice and submit only requested documents. Do not upload unnecessary personal information.

# Technical Support
For portal access problems, contact the campus IT help desk. Do not send passwords or OTPs in support requests. Include a brief description and a screenshot only if it contains no private information.
